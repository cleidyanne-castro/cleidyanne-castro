# Mobile verification checklist

## Browser checks

| Check | Expected result | Status |
| --- | --- | --- |
| Viewport meta tag | The layout follows the device width | Present in both pages |
| Navigation | Primary links remain reachable on narrow screens | Passed in the responsive CSS review |
| Hero layout | Text and artwork stack into one column | Covered by the mobile breakpoint |
| Project cards | Cards use one column and do not overflow horizontally | Covered by the mobile breakpoint |
| Contact links | Links wrap when needed | Covered by the mobile breakpoint |
| Reduced motion | Decorative animation can be disabled by the user preference | Present |
| Keyboard focus | Links and filter buttons remain operable | Requires browser keyboard check |

## Physical device checks

These checks require a real phone and are not claimed as completed in this repository:

1. Open the live page on a phone over a mobile network.
2. Check text size, contrast, and tap targets.
3. Open each project link and the CV link.
4. Confirm there is no horizontal scrolling.
5. Record the device, browser, date, and result.
